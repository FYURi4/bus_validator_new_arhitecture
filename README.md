/*BUS VALIDATOR SYSTEM*\
Аддон Bus Validator System - добавляет автоматическую систему для оплаты проезда пассажирами. Аппарат для оплаты проезда крепится на поручень. Для использования валидатора нужно использовать транспортную или банковскую карточку, приложите карту к экрану. При успешной оплате проезда появится надпись "Проезд оплачен" и стоимость проезда, при не удачной оплате проезда появится надпись "Ошибка проезд не оплачен". При не удачной оплате приложите карту еще раз или воспользуйтесь другим способом оплаты проезда.

Взаимодействие с валидатором в Garry's Mod:
- Установите валидатор на троллейбусе.
- Возьмите транспортную карту, подойдите к валидатору и нажимайте кнопку "E", до успешной оплаты проезда.

Реализована синхронизация с выбранными маршрутами.

Модели валидаторов:
-AQSI_CUBE
-BM20

Весь добавленный транспорт находится по пути sv.db > svas_agreelist

Для управления таблицами [*.db] рекомендуется использовать программное обеспечение SQLite.
